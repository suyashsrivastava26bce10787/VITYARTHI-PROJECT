# Smart Expense Tracker

VITyarthi Python Project for CSE1021.

## Features

1. Add Expense
2. Show Expenses
3. Delete Expense
4. Total Expense
5. Highest Expense
6. Category Expense
7. Set Budget
8. Budget Status
9. Expense Report

   * Spending by Category
   * Average Expense
   * Highest Spending Category

## Project Modules

* `main.py` - Main menu and program control
* `expense.py` - Add, show and delete expenses
* `analysis.py` - Analyze expenses
* `budget.py` - Set and check budget
* `reports.py` - Generate expense reports

## Concepts Used

* Variables
* Input and output
* Functions
* Lists
* Dictionaries
* `if-else` statements
* `for` loop
* `while` loop
* Arithmetic operations
* Summation
* Finding maximum
* Basic searching
* Python modules
* Importing functions

## Requirements

* Python 3
* No external libraries required

## Run

Open the project folder in VS Code and run:

```bash
python main.py
```

## Note

Expenses are stored only while the program is running. The project does not use a database.
