# Smart Expense Tracker

## Problem Statement

Students spend money on food, transport, shopping and other activities.
It can be difficult to keep track of total spending and understand where the money is being spent.

This project provides a simple Python program for recording expenses, analyzing spending and checking expenses against a budget.

## Objectives

* Record expenses.
* Display expenses.
* Delete expenses.
* Calculate total spending.
* Find the highest expense.
* Calculate spending for a category.
* Set a budget.
* Check budget status.
* Generate a simple expense report.
* Calculate average spending.
* Find the category with the highest spending.

## Target Users

Students and individuals who want to track their personal expenses in a simple way.

## Functional Modules

1. Expense Management

   * Add expenses
   * Show expenses
   * Delete expenses

2. Expense Analysis

   * Calculate total expense
   * Find highest expense
   * Calculate category-wise expense

3. Budget Management

   * Set budget
   * Check budget status

4. Expense Reports

   * Display spending by category
   * Calculate average expense
   * Find highest spending category
