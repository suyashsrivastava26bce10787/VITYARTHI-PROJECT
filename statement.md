# Smart Expense Tracker

## Problem Statement
Students spend money on food, transport, shopping and other activities.
It can be difficult to keep track of total spending.

This project provides a simple Python program for recording expenses
and checking spending against a budget.

## Objectives
- Record expenses.
- Display expenses.
- Delete expenses.
- Calculate total spending.
- Find the highest expense.
- Calculate spending for a category.
- Set a budget.
- Check budget status.

## Target Users
Students and individuals who want to track personal expenses.

## Functional Modules
1. Expense Management
2. Expense Analysis
3. Budget Management

## Technology
Python
